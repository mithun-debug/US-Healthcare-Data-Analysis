#  US Healthcare Statistical Analysis using Python

A comprehensive **Exploratory Data Analysis (EDA)** and **Statistical Analysis** project performed on a US Healthcare dataset containing **10,000 patient records**. This project demonstrates how Python and statistical techniques can be used to extract meaningful business insights, validate hypotheses, and support data-driven healthcare decision-making.

---

##  Project Overview

Healthcare organizations generate large volumes of patient and billing data every day. This project analyzes healthcare records to identify trends in patient demographics, disease prevalence, insurance utilization, hospital admissions, and billing patterns.

Beyond traditional EDA, this project applies **inferential statistical methods** to determine whether observed differences and relationships are statistically significant.

---

##  Business Objective

The primary objectives of this analysis are to:

- Analyze patient demographics and healthcare utilization.
- Identify the most common medical conditions.
- Examine hospital admission patterns.
- Evaluate billing trends across different patient groups.
- Study insurance provider utilization.
- Validate findings using statistical hypothesis testing.
- Generate actionable business recommendations for healthcare management.

# Statistical Analysis

The following statistical methods were applied to validate business insights.

| Statistical Test | Purpose |
|------------------|----------|
| Descriptive Statistics | Summarize billing amount distribution |
| 95% Confidence Interval | Estimate the true average billing amount |
| Independent Samples t-Test | Compare billing amounts between male and female patients |
| One-Way ANOVA | Compare billing amounts across admission types |
| Chi-Square Test | Determine association between gender and admission type |

---

# Hypothesis Testing Results

| Test | Result | Conclusion |
|------|---------|------------|
| Independent Samples t-Test | t = 0.3989, p = 0.6900 | No significant difference in billing between male and female patients |
| One-Way ANOVA | F = 8.6972, p = 0.0002 | Admission type significantly influences billing amount |
| Chi-Square Test | χ² = 13.5597, p = 0.0011 | Gender and admission type are significantly associated |

---

#  Key Business Findings

- Hypertension was the most frequently diagnosed medical condition.
- Emergency admissions represented the highest proportion of hospital visits.
- Medicare covered the largest number of patients.
- Cancer generated the highest billing revenue among medical conditions.
- Gender was **not** a statistically significant factor influencing hospital billing amounts.
- Admission type had a statistically significant effect on billing costs.
- Gender and admission type showed a statistically significant association.
- Billing amounts exhibited considerable variability, indicating diverse treatment costs.

# Business Recommendations

- Strengthen preventive healthcare initiatives for hypertension.
- Improve staffing and resource allocation in emergency departments.
- Review billing practices across different admission types.
- Monitor admission trends for operational planning.
- Use statistical insights to support budgeting and healthcare policy decisions.
